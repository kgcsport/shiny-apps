How to use the Game Builder

1 — Choose a mode

Single-screen — one display projected to the class. You control it; students watch and call out answers. Best for demonstrations, live polls, or instructor-led experiments.

Multi-device ⚡ — each student opens the game URL on their own device and interacts simultaneously. All state is public (everyone sees everyone's moves). Good for: contribution games, auctions, public-goods problems, coordination games.

2 — Describe your game

Type a plain-language description in the chat box. Be as specific or vague as you like — the AI picks sensible defaults and you can always iterate. Example prompts:

  • "A supply and demand diagram where I can drag the curves."
  • "A 5-round public goods game. Each of 10 students contributes 0–20 tokens. Show running totals."
  • "Ultimatum game. One proposer splits $10. Responder accepts or rejects. Show outcome immediately."

3 — Iterate in conversation

The AI generates a working game right away. Keep refining by replying naturally:

  • "Make the timer 90 seconds instead of 60."
  • "Add a leaderboard sorted by total earnings."
  • "Switch to a dark color scheme."
  • "Add a teacher view that shows the class average."

4 — Save & share

Click Save & share to store the game and get a permanent link. You'll be prompted to give it a title. For multi-device games the link is the room URL — every student who opens it joins the live session.

5 — Reload from the Library

Click 📚 Library to browse saved games and built-in templates. Loading a game seeds the chat with its HTML so follow-up messages refine it further.

Saving & reloading games

Download HTML ↓ — instant. Saves a self-contained file that opens in any browser. Use this to back up your game.

Download Bundle ↓ — takes 30–60 seconds. Downloads a ZIP with the HTML file plus R Shiny and Python Streamlit versions and Dockerfiles for each.

To reload a downloaded game: open the Library (📚), click ↑ Upload HTML, and pick the .html file. Your last session is also restored automatically on return.

API key

If the server provides a demo key you can use it immediately (limited to gpt-4o-mini). Add your own Anthropic, OpenAI, or OpenRouter key via + Use your own key to unlock better models and higher limits.

Multi-device limitations

GameSync (the built-in sync layer) keeps all state fully public and in-memory — it resets if the server restarts. For games that need private per-student state, persistent data between sessions, or an instructor admin panel, see the Advanced guide →
